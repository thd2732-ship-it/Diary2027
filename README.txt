2027 다이어리 (PWA)
1) 이 폴더 전체를 https 주소에 올리세요 (Netlify Drop / GitHub Pages / Cloudflare Pages 등, 무료).
2) 폰 Chrome(또는 삼성 인터넷)으로 접속 -> 메뉴 -> "홈 화면에 추가" / "앱 설치".
3) 홈 화면 아이콘으로 실행하면 이얼리플랜에서 시작합니다.
* 데이터는 폰 안(IndexedDB)에 저장됩니다. 주기적으로 [이동 > 백업 파일 저장]을 해 두세요.
* APK가 필요하면 위 주소를 PWABuilder(pwabuilder.com)에 넣어 Android 패키지로 만들 수 있습니다.
